# FR-14

If an incoming reading is of the wrong type, missing, or outside any physically possible range, the system shall reject that specific reading, log it as invalid, and continue operating normally.

## How it is tested

- **Method:** inject (draft)
- **Injection:** [[07-demo-control-panel|I-08]] Bad reading
- **Check:** Send the three bad readings. Each is rejected, logged as invalid, and the system carries on.
