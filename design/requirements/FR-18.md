# FR-18

An Engineer shall be able to place a piece of equipment into maintenance mode for a stated duration. During maintenance, the system pauses sensor readings and new fault alerts for that equipment.

## How it is tested

- **Method:** inject (draft)
- **Injection:** [[07-demo-control-panel|I-03]] Sustained critical
- **Check:** Put a machine in maintenance mode, then run I-03 on it. Readings stop and no new alert is raised.
