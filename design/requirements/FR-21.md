# FR-21

On restart after a shutdown or crash, the system shall resume monitoring using the last known configuration and shall not treat equipment status as unknown once fresh readings are received.

## How it is tested

- **Method:** inject (draft)
- **Injection:** [[09-demo-control-panel|I-13]] Restart the system
- **Check:** Restart the system. It resumes with the last configuration and shows status once fresh readings arrive.

Status is one of: built, simulated, left-out, not-set. Change the `status` line above.
