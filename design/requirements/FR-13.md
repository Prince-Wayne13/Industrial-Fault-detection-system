# FR-13

If no reading arrives for a parameter for 3 seconds, the system shall flag that parameter as having a sensor fault and display this on the dashboard, instead of continuing to show the last known reading as current.

## How it is tested

- **Method:** inject (draft)
- **Injection:** [[07-demo-control-panel|I-07]] Sensor goes silent
- **Check:** Silence one parameter for 3 seconds. Its number is replaced by the "sensor fault" mark.
