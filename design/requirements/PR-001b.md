# PR-001b

If an alert is shown more than 2 seconds after its status confirms the fault, the system shall still show the alert, write the delay to the log, and show an "alerts delayed" notice on the dashboard.

Status is one of: built, simulated, left-out, not-set. Change the `status` line above.
