# FR-25

All system components shall use a synchronized time source, so that fault timestamps and response-time measurements (see Section 3.3, Performance Requirements) are consistent across the system.

## How to test (draft)

- **Method:** inspect
- **Seeded scenario:** Normal running
- **What to do:** Compare the time stamps from different parts of the system for the same reading.
- **Passes if:** They agree.
