# FR-14

If an incoming reading is of the wrong type, missing, or outside any physically possible range, the system shall reject that specific reading, log it as invalid, and continue operating normally.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Bad reading
- **What to do:** Send the three kinds of bad reading.
- **Passes if:** Each one is kept out, logged as invalid, and the system carries on.

Status is one of: built, simulated, left-out, not-set. Change the `status` line above.
