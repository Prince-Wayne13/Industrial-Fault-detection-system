# FR-16

The system shall not raise a duplicate alert for a fault condition that is already open and unacknowledged; it shall only raise a new alert once the condition has returned to normal and then reoccurs.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Fault returns
- **What to do:** Let a fault stay open, then clear, then return.
- **Passes if:** No second alert while it is open. A new alert only after it cleared and came back.
