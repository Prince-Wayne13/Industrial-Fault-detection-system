# FR-17

The system shall support a fault lifecycle of at least: open → acknowledged → resolved. An Engineer shall be able to mark an acknowledged fault as resolved, and the system shall record when this happens.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Sustained warning
- **What to do:** As an Engineer, mark the acknowledged fault resolved. Try as an Operator.
- **Passes if:** The Engineer can, and the time is recorded. The Operator cannot.
