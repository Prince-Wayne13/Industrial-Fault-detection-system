# FR-20

If the data storage component becomes unavailable or full, the system shall retain new readings in temporary local storage and shall not crash or silently discard data without logging the event.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Storage fails
- **What to do:** Make the main store unavailable.
- **Passes if:** New readings are kept in temporary storage, the system keeps running, and the event is logged.
