# FR-18

An Engineer shall be able to place a piece of equipment into maintenance mode for a stated duration, during which the system continues recording sensor readings but suspends new fault alerts for that equipment.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Maintenance
- **What to do:** As an Engineer, turn on maintenance for a stated time.
- **Passes if:** Readings keep recording. New fault alerts for that machine pause.
