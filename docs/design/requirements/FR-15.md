# FR-15

If two or more parameters on the same equipment become abnormal at the same time, the system shall raise a separate fault record for each affected parameter rather than combining them into a single alert.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Two faults at once
- **What to do:** Play the scenario.
- **Passes if:** Two separate fault records appear, one for each parameter.
