# FR-28b

The system shall not require a mix of capitals, numbers or symbols in a password, and shall not force password changes on a schedule.

## How to test (draft)

- **Method:** look
- **Seeded scenario:** Login checks
- **What to do:** Set a long password with only lowercase letters.
- **Passes if:** It is accepted, and nothing forces a change later.
