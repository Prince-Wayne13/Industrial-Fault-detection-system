# FR-11

The system shall support both a near-range and a remote-range connection mode for accessing equipment data from the dashboard. The final demonstration shall provide a selectable simulated mode for each connection type.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Near and remote mode
- **What to do:** Switch the demo between near and remote mode.
- **Passes if:** The dashboard shows the same equipment data in both modes.
