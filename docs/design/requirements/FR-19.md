# FR-19

If a piece of equipment remains in maintenance mode beyond its stated duration, the system shall flag this as overdue on the dashboard.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Maintenance
- **What to do:** Let the stated time run out.
- **Passes if:** The machine shows an overdue mark.
