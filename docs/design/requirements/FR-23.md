# FR-23

If an operating threshold (normal/warning/critical limit) is changed, the system shall retain the previous value and the date of change, rather than overwriting it silently.

## How to test (draft)

- **Method:** inject
- **Seeded scenario:** Limit change
- **What to do:** Change a limit, then look at its earlier values.
- **Passes if:** The old value and the date of change are still shown.

Status is one of: built, simulated, left-out, not-set. Change the `status` line above.
