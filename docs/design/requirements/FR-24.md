# FR-24

The system shall support monitoring more than one piece of equipment within the same category (e.g. multiple motors) as separately identifiable units, each with its own status and fault history.

## How to test (draft)

- **Method:** look
- **Seeded scenario:** Normal running
- **What to do:** Open the Overview and the machines list.
- **Passes if:** Several motors appear as separate units, each with its own status and fault history.

Status is one of: built, simulated, left-out, not-set. Change the `status` line above.
