# FR-8a

When a fault is acknowledged, the system shall record which user did it and when.

## How to test (draft)

- **Method:** look
- **Seeded scenario:** Sustained warning
- **What to do:** After acknowledging, open the machine's fault list.
- **Passes if:** It shows who acknowledged and when.
